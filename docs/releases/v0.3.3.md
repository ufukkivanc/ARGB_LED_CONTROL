## ARGB LED Controller v0.3.3

### Değişiklikler
- **Yeni sabit GPIO eşlemesi:** **CH1 → GPIO19, CH2 → GPIO21**, CH3 → GPIO22, CH4 → GPIO23 (v0.3.2: CH1 = 18, CH2 = 19).
  **CH1 ve CH2 şeritlerini yeni pinlere bağlayın**; CH3 ve CH4 değişmedi. Pinler arayüzde gösterilmez ve değiştirilemez;
  geliştiriciler için tek merkez `firmware/include/config.h` → `LED_CHANNEL_HW`.
- GPIO21 firmware'de başka bir bileşen tarafından kullanılmaz (I2C/SPI yok; rezerve, strapping veya flash pini değil).
- Güncellemede kayıtlı ayarlar (LED sayısı, renk, efekt, palet, parlaklık, Wi-Fi, eşleştirmeler) korunur; NVS'teki eski pin değeri
  yok sayılır (seri logda örn. `Fixed GPIO 19 (saved value 18 ignored)`).
- Windows uygulaması, iPhone paneli, API (protokol sürümü 1) ve LED efektlerinde işlev değişikliği yoktur; Windows uygulaması yalnızca
  sürüm numarası için yeniden paketlendi.

Ayrıntılar: [CHANGELOG.md](https://github.com/ufukkivanc/ARGB_LED_CONTROL/blob/main/CHANGELOG.md) · Protokol: docs/PROTOCOL.md §3.8

### Doğrulama durumu
**Doğrulandı**
- Gerçek ESP32'de (ESP32-D0WD-V3, v0.3.2 ayarları olan cihaz, NVS korunarak güncelleme) aynı pin eşlemesine sahip ön derleme
  (kaynak kodu bu sürümle aynı, yalnızca sürüm dizesi `0.3.2`): açılış logunda kanallar GPIO 19/21/22/23, NVS'teki eski pin değerleri
  yok sayıldı, 4 kanal × 12 LED, Wi-Fi bilgileri ve eşleştirmeler korundu; çökme yok.
- Firmware derlemesi (WLED'li ve WLED'siz), C++ ana bilgisayar testleri (370 + 1190), Flutter testleri (169), Windows Release derlemesi
  ve kurulum paketi üretimi; `SHA256SUMS.txt` doğrulandı, `merged.bin` içindeki uygulama bölümü `app.bin` ile bayt bayt aynı.
- Fiziksel doğrulama (kullanıcı tarafından, gerçek donanımda): GPIO 19/21/22/23 üzerindeki şeritlerde sorun görülmedi.

**Henüz doğrulanmadı**
- Bu sürümün `app.bin` / `merged.bin` dosyalarının cihaza yazılıp `Firmware 0.3.3` ile açılması (cihaz o sırada bağlı değildi).
- API / WebSocket üzerinden dört kanal testi (`firmware/test_host/multichannel_device_test.py` yeni pinlerle hazır, çalıştırılmadı:
  cihaz kayıtlı Wi-Fi ağını bulamayıp kurulum AP'sine geçmişti).
- Kurulum paketinin yüklenip çalıştırılması.
